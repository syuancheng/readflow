### 1. 老师笔记失败后的重试风暴
- **根因**：`shouldUpdateNote` 只认「上次成功更新」的游标与时间；失败时游标不动 → 条件恒成立 → 每次满足条件的讲解都重新调模型（用户实测 8 次请求打模型 8 次）。
- **修复**：新增纯函数 `src/lib/learner/note-throttle.ts`
  - `NOTE_FAILURE_COOLDOWN_MS = 60 * 60 * 1000`（失败后 1 小时）
  - `NOTE_MAX_ATTEMPTS_PER_DAY = 3`（成功与否都算）
  - `noteDayKey` 用本机本地日期；失败冷却按**绝对时间**算，跨天不提前解除；当日次数按日期键清零
  - `noteBlockReason(state, now)` → `"failure_cooldown" | "daily_limit" | null`
  - `settleNoteAttempt(state, { success, now })` 结算一次尝试
- **接线**：`note-generator.ts` 调模型前过闸门，`finally` 里结算一次尝试（成功/校验失败/抛错/超时都算一次）。
  不满足 25 次 + 24 小时、或站点没配模型 → **不算一次尝试**。
- **冷却状态放进程内存（Map），不加列**。理由：不需要迁移、不增加失败时的 DB 写入、与已有 `running` 并发锁同生命周期；重启清空可接受；**权威的成功节奏仍是落库的 `note_updated_at` / `note_lookup_cursor`**。

### 2. completeChat 60 秒超时
- `src/lib/providers.ts` 新增 `COMPLETE_CHAT_TIMEOUT_MS = 60_000` 与 `runWithChatTimeout(fn, ms, externalSignal)`。
- OpenAI SDK 分支传 `{ signal }`（第二参数），Anthropic fetch 分支传 `signal`；两条路径共用同一硬超时。
- 超时 abort 底层请求并抛 `ProviderError(504)` → 笔记生成按失败处理 → 进入冷却。
- `ChatOptions.timeoutMs` 只给单测用，正常调用不要传。

## P32-修复 · D5e 偶发失败（提交 `c5ed30e`，已推送 `feat/p32-p33`）

用户纠正：D5e 是 d563f06（第 3 步）**新加**的断言，所以「不要改已有测试的断言」不适用，修稳它是自己的责任。

### 根因（用户诊断，经代码核对确认）
- D5e 用鼠标物理拖选短语触发划词，但插件 `extension/src/content.js` 的 `connectObserver` 用 MutationObserver 监听页面变化，变化后 **700ms** 触发 `clearHighlights()` + `applyHighlights()` 重建高亮，把选区所在的文本节点替换掉（`replaceWith` 文本节点）。
- 正在进行的物理拖选选区基于这些文本节点，被重建后就丢失 → 退化成「点击单个词、词典命中、不触发 AI 讲解」→ 等不到「回答完成」（offAiDone 超时 false）→ 判失败。约 1/3 概率。

### 修复（scripts/e2e-extension.mjs D5e 段）
- **等高亮稳定再操作**：`waitForTimeout(2500)`，让 resync + MutationObserver 的 700ms debounce 都 settle，保证设置选区后不会被立刻重建弄丢。
- **用代码直接设置选区**：`document.createTreeWalker` 找 OFF_PHRASE（单文本节点 `<p id="p31b">A careful engineer will scrutinize the deployment pipeline twice.</p>`，短语就在该节点内） → `Range.setStart/setEnd` + `Selection.addRange`。
- **派发真实 click 到 body**：复用插件既有的 `click→select` 划词路径（content.js 1098 行的 click 监听器读 `window.getSelection()` 触发 lookupSelection，不引入新逻辑）。DOM 事件跨 world，isolated world 的监听器能收到；选区是 DOM 级、跨 world 共享，content.js 读到我设置的选区。
- **断言语义不变**：站点开关 off 时插件侧栏不显示反馈行（先确认讲解已完成）。
- 移除了原物理拖选 + fallback 物理点击分支。
