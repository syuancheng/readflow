- 小卡片换成 380px 覆盖式右侧栏；点词自动记录、可取消；词典未命中自动请 AI；回答走
  `chrome.runtime.connect` port 流式追加，讲完写回同一条 `contexts.ai_gloss`。

**踩过的坑（下次直接照做）**
1. `sendMessage` 经 background 的 `apiRequest` 返回的是 `{ json }` / `{ text }` 包装，不是响应体本身。
   直接 `applyPayload(res)` 会让 `s.quote` 变 undefined，`askOptions()` 里 `s.quote.length` 抛
   「Cannot read properties of undefined (reading 'length')」，catch 里再渲染又抛一次 → 侧栏永远停在
   「查词典中…」。取值要 `res?.json ?? res`，并给 `applyPayload` 留 `payload.quote` 校验。
2. 侧栏是「先开壳再填内容」，E2E 里只等 `.rf-word` 出现就点空白，记录还没回来 → 迟到的响应把侧栏
   重新画出来。修法两层：产品侧加 panelSeq，测试侧等 `.rf-dict` 不再是「查词典中」再继续。
3. 侧栏固定占右侧 380px，测试里「点行尾右边空白」会点在侧栏上；空白点要选左边页边距。
4. 侧栏有 200ms 滑入动画，量位置前要等 `left === innerWidth - 380`，否则量到 translateX(100%) 的位置。
5. Playwright 对**后台标签页**点不动，切页前要 `page.bringToFront()`。
6. 「自动 AI 讲解」用本地假模型验证：写 `settings`（user_id='local'）的
   `ai.activeProvider=custom` + `ai.custom.baseUrl=<本地>/v1`，假端点回 OpenAI 风格 SSE，离线可重复。
7. 本机 `grep` 对部分 .ts/.mjs 会被 file(1) 误判成 `Java source` 而静默无输出，**一律用 Grep 工具**。
