# 2026-11-19 工作日志

## 两层文章上下文（selected sentence + 150 词近前文）

- 需求：选词后追问「整句没看懂」时 AI 缺少指代背景（截图 `plain one` 指三句外的 `loaf cake`）。定稿为两层上下文：第一层所在句=讲的对象，第二层往前 150 词=理解指代的背景。
- 关键设计决策（用户逐轮确认）：
  - 窗口单位用**词数**不用句数（句长波动大），150 词按句边界截断、跨段继续往前取、倒序排列、保留段首 `Woman:`/`Man:` 说话人标签。
  - 窗口只依赖「段落原文 + 选区锚点」，**不读 savedSet 等可变状态**——否则用户收了新词再追问，窗口变了会毁掉 system 前缀缓存。
  - 两层放进**独立 system message**，排在 rules 之后、history 之前；每轮都带（与 agent loop 同理：HTTP 无状态，system 每轮必发，KV cache 省的是计算不是传输）。
  - 提示词明确分层：所在句是对象，近前文是背景、别逐字翻译、别当学生的问题。
  - 历史压缩保持现状：首次钉住 + 最近 3 轮完整 + 中间压要点（用户确认「就是这样的」）。
  - 做卡缓存未命中时只放 layer1（所在句）——`ctx` 只有当前段落，拿不到前序段落；命中时前缀复用 `cached.messages`，那里两层齐全。
