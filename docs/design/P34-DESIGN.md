## 1. 设计简报（按 PR-01 顺序）

### 1.1 中心点（C-02 / TIP-03）
- 阅读页右栏：**讲解正文**。U1 是附属信息：12px、次要灰、无边框无阴影、不用绿色主按钮。
- 设置页「AI 眼中的你」：**紫色笔记块**。U2 是块外的一行次要说明。

### 1.2 分组 · 亲密性（P-01 ~ P-11）

| 组 | 成员 | 组内间距（实测） | 组间间距 |
|---|---|---|---|
| 一段讲解 | 「你问：…」/ 回答正文 / U1 | 8px（`.rf-feedback-row { margin-top: 8px }`） | 16px（沿用 `mt-4`） |
| U1 内部 | 「这次讲得：」/ 三个选项 | 4px（`gap: 4px`） | — |
| 笔记 + U2 | 紫色块 / 更新说明 | 8px（`.rf-note-meta { margin: 8px 0 0 }`） | 16px（到下方按钮） |

视线路径：「你问：…」→ 回答正文 → 反馈行 → 下一段讲解 /「问 AI」按钮组。DOM 顺序与视觉顺序一致。

### 1.3 对齐（A-01 ~ A-11）
- 唯一主对齐线：右栏内容区左边缘（x = 896px @1440；x = 26px @390），「AI 释义」标签、讲解正文、「这次讲得：」、「问 AI」按钮都在这条线上（见 `feedback-rated-1440.png`）。
- 设置页：U2 左边缘 = 紫色块左边缘 = 「主要难点」等标签左边缘。
- 唯一文本对齐：左对齐。无居中、无两端对齐、无绝对定位。

### 1.4 重复（R-01 ~ R-09）
- 加强已有重复：讲解当时与回看用同一个 `FeedbackRow`、同一套类名，选中态（成功绿 + ✓ + 浅绿底）不变；U2 复用设置页次要说明的形态（`--rf-text-secondary` + `--rf-text-sm`，与「依据：…」一致）；圆角只用 `--rf-radius-xs`（按钮）与既有 `--rf-radius-md`（笔记块）。
- 新增重复元素：无。

### 1.5 对比（C-01 ~ C-09 / TX-01 ~ TX-11）

| 相邻元素 | 字号 | 对比维度 |
|---|---|---|
| U1 选中 vs 未选中 | 12 / 12 | 颜色（#3f7f00 vs #6b6b6b）+ 字重（700 vs 400，原为 600 vs 700 的假对比，已改）+ 形状（✓ + 浅绿底） |
| U1 前缀 vs 选项 | 12 / 12 | 同组，刻意相同；选项靠悬停底色与按下缩放表明可点 |
| U1 vs 讲解正文 | 12 / 14 | 例外 E-06 |
| U2 vs 笔记正文 | 14 / 14 | 结构（块外 vs 块内）+ 颜色（次要灰 vs AI 紫） |

### 1.6 配色（COL-01 ~ COL-13）
- 关系：互补——黄绿（品牌 / 成功）与紫（AI 产出），大面积中性灰白；本期不新增颜色。
- 对比度（WCAG 相对亮度，2026-11-14 实测，令牌未变）：

| 文字 | 背景 | 对比度 |
|---|---|---|
| `--rf-success-text` #3f7f00 | `--rf-success-soft` #f1fbe7 | 4.64 : 1 |
| `--rf-text-secondary` #6b6b6b | #ffffff | 5.33 : 1 |
| `--rf-text-primary` #3c3c3c | `--rf-bg-hover` #f7f7f7 | 10.30 : 1 |
| `--rf-text-secondary` #6b6b6b | `--rf-bg-hover` #f7f7f7 | 4.97 : 1 |

- 暖色面积：0。

### 1.7 字体（TC / TF / TX / T）
- 单一字族 `--rf-font-sans`（DM Sans + 苹方，无衬线体），协调方案（TF-01）；不用 Times / Arial / Helvetica / Sand；无 Script / Decorative。
- 中文全角标点、「」引号、`·` 分隔；无下划线、无全大写；U2 用 `text-wrap: pretty`。

### 1.8 媒介与状态
- 390px：U1 一行约 190px 放得下；U2 允许换行、左对齐；`shot()` 断言无横向溢出（通过）。
- 状态：未评价 / 已评价（随时可改）；悬停浅灰底 + 主文字色；按下 `scale(0.92)`；焦点环沿用全站 `:focus-visible`；✓ 弹出动画在 `prefers-reduced-motion: reduce` 下关闭。
- 深色模式、打印：产品没有（E-05）。
- 言之有理（PR-03）：回看时不加「补评 / 修改」说明——与讲解当时相同的一行本身就表示可点可改。

## 5. 与实现说明的偏离（交付时一并说明）

| 位置 | 实现说明写的 | 实际 | 原因 |
|---|---|---|---|
| §7 U2，来源 `user` | 「你修改过 · {时间}」 | 「你修改过 · AI 老师整理时会参考这段内容」，不写时间 | 用户改笔记后，下一次每晚整理会改写它；告诉用户「改的内容会被参考」比时间更有用 |
| §7 还没有笔记时 | 「今晚会整理一次」 | 新动静不足 10 次：「再攒 N 次查词或反馈，AI 老师当晚就会写下第一份观察」；已够：「AI 老师今晚会写下第一份观察」 | 每晚整理有 10 次门槛，「今晚会整理」在不够 10 次时不成立 |
| §8.10 `@import` 位置 | `globals.css` 末尾 | `globals.css` 顶部，紧跟 tokens 之后 | CSS 规定 `@import` 必须在其它规则之前，写在末尾会被浏览器忽略 |
