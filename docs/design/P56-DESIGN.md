# P56 色板：一个绿色家族（设计走查后的第四轮）

- 起因：用户给了国泰航空网站的参考——Logo 是亮绿，但界面不用亮绿做大面积；浅灰的地方可以用很浅很浅的绿，黑色按钮可以用暗淡的墨绿。要求**先构建网站主要用的颜色体系**，再改其他问题。
- 色板与角色见 `docs/design-system.md` §1.0。令牌在 `src/styles/tokens.css`：`--rf-gray-*` 改成带一点绿的灰（9 档）、新增 `--rf-forest-700/600`（墨绿）、`--rf-brand-soft`（浅绿）；`--rf-accent` 指向墨绿。因为全站颜色都走语义令牌，改令牌一次生效。
- 对比度（已核）：正文 `#2a3326` 白底 13.1:1；次要文字 `#5b6853` 白底 5.9:1、在 `#f6f8f4` 5.5:1、在 `#edf2e9` 5.2:1；白字在墨绿 9.7:1、悬停色 7.1:1。

## 同时修的 4 处（用户同轮提出）
1. **导入框的「分类」：**去掉左边的「分类」两个字，选择框里第一项就是提示「选择分类（可选）」，和标题输入框、正文框左右对齐。
2. **推送进度：**「推送全部」按钮缩小（32px 高）；又长又黑的横向进度条换成一个 20px 的小圆环（`ProgressRing`）加一行字「正在推送：已推送 3 / 共 10」。
3. **颜色恢复：**悬停 / 拖选一个词的底色恢复成原来的浅绿（`--duo-green-soft` 不再指向灰）；「+1 词」恢复品牌亮绿。
4. **下划线：**AI 回答里句子结构的下划线（`MarkdownText`）恢复绿色（`--rf-brand`）。
