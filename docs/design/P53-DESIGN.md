# P53 第二阶段：统一组件（图标、表单控件）——设计走查后的整体改版

- 承接 P52 的走查（`docs/design/P52-DESIGN.md`）。本阶段：**emoji → 统一线条图标**、**原生下拉 / 复选框 / 单选框 → 统一自绘样式**、**格式小按钮与词库筛选 chip 同一形态**。
- 第三阶段另做：推送完成流程、欢迎问卷版式、首页列表行的元素精简。

## 0. 问题（对照规则）
| 问题 | 规则 |
|---|---|
| 35 处图标 / 状态符号里有十几种彩色 emoji（战绩 ⚡🔥🏅📚、账户菜单 👤⚙🔑↪、底部导航 📖⚡🏆、导入页 📋📁🔗、编辑 ✏️、空状态 🔍🎯📝🃏、音色 🔊）：不同系统上长得不一样，彩色与中性界面冲突，没有统一体系 | R-01、COL-09 |
| 浏览器自带的下拉和复选框（问卷、导入、推送栏）与词库里自绘的控件并存 | R-01、R-06 |
| 格式小按钮（2px 粗边）与词库筛选 chip（1px）不是同一种形态 | R-01 |

## 1. 设计简报
- **重复（R）**：新增唯一的图标来源 `Icon` 组件（15 个单色线条图标，24×24、线宽 1.8、圆角端点，颜色跟随文字）；所有下拉 = 白底 1px 描边 + 灰色小箭头；复选框 = 20px、radius xs、选中近黑填充 + 白色对勾；单选框 = 圆形，选中近黑圆点；聚焦环统一 `--rf-focus-ring`；格式按钮 = 筛选 chip（1px、胶囊、600）。
- **对比**：未选中（白底灰边）对选中（近黑实心）。
- **配色**：不新增色值；图标用文字色；空状态大图标用 `--rf-gray-400`；星标：灰色空心 / 琥珀色实心。
- **取舍**：战绩页四张统计卡**不放图标**（只有标签和大数字），更接近 Claude 的克制；图标只放在「有操作含义」的地方（导航、菜单、标签页、编辑）。
- **不改**：AI 回答正文里模型自己写的 emoji（🧩、⚠️ 等）来自系统提示词的输出格式，改动它会影响解析，不在本阶段；✓ ↗ → ★（柯林斯星级）这类文字符号保留（单色、跟随文字色）。
