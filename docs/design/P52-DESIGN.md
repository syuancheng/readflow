# P52 第一阶段：中性色系统（设计走查后的整体改版，《写给大家看的设计书》前端规范）

- 起因：用户指出整站绿色太多（绿按钮、绿进度条……）、还有紫色，「Claude Code 的 Logo 是棕色，但它没有把按钮、进度条做成棕色」。要求从设计师角度走查整站、找出所有问题再改。
- 走查截图：`.verify/audit/`（`scripts/audit-shots.mjs` 生成；改后重跑可对比）。
- 分三阶段，各自单独合并：**① 中性色系统（本阶段）**；② 统一组件（3D 按钮之外的零散样式、表单控件、emoji → 图标）；③ 页面级修复（推送完成流程、欢迎问卷、首页列表行、战绩页）。

## 0. 走查发现的问题（对照规则）
| 问题 | 规则 |
|---|---|
| 品牌绿当界面装饰色：主按钮、进度条（阅读 / 推送 / 战绩）、导航下划线、头像、开关；紫色用在 AI（发送按钮、建议按钮、菜单悬停）；琥珀色的 XP 和 🔥 徽章；难度徽章三种颜色——五种彩色，没有主次，没有一个在「表示什么」 | COL-09、R-05、C-02 |
| 两套按钮并存：3D 厚底边按钮（首页、问卷、导入）与扁平按钮（词库、对话框） | R-01、R-06 |
| 推送完成后整根绿色进度条和禁用的绿按钮留在页面上（第三阶段处理） | C-06 |

## 1. 设计简报（本阶段）

### 1.1 中心点
界面是中性的，让**内容**（文章、词、释义）成为中心；颜色只在表示状态时才出现。

### 1.2–1.5 分组 / 对齐 / 重复 / 对比
本阶段不改版式，只换颜色与按钮形态。重复：全站主按钮 = 近黑实心 + 白字；次要按钮 = 白底 1px 描边；所有按钮扁平（去掉 4px 实体底边）。对比：主按钮（近黑实心）对次要按钮（描边）是页面里最强的对比，一屏只有一个主按钮。

### 1.6 配色（COL）
- **中性为主**：灰阶 + 近黑主色（`--rf-accent` = `--rf-gray-900`）。
- **品牌绿只在 Logo**（`--rf-brand`）。头像改为深灰底。
- **颜色只表示状态**：成功 = 绿色 ✓（`--rf-success-*`）；删除 / 错误 = 红；链接 / 聚焦环 = 蓝；星标 = 琥珀。
- **去掉紫色**：`--rf-ai*` 改为灰阶，AI 靠版式（右边是你、左边是 AI）区分。
- **难度徽章**统一灰色小标签（`--rf-level-*` 全灰）；**学习日历**改灰阶热力。
- **保留**：阅读器里「查过的词」的绿色下划线、悬停 / 选中的浅绿底（用户 2026-11-20 确认没问题）——这是整站唯一保留的内容层绿色。
- 去掉首页的 ⚡XP 和 🔥 徽章（XP = 今天收的词 × 10，没有实际意义）。

### 1.7–1.8 字体 / 媒介
不变。窄屏、打印不受影响。

## 2. 实现方式
- `src/styles/tokens.css`：重写语义层——`--rf-accent*` 改近黑、新增 `--rf-brand*`、`--rf-ai*` / `--rf-level-*` / `--rf-heat-*` 改灰阶；`--rf-highlight-*` 保持绿色。
- `src/app/globals.css`：旧的 `--duo-green*` / `--duo-purple*` 别名改指向中性（所有历史引用一次生效）；`.duo-btn*`、`.duo-btn-sm`、`.st-btn-primary`、`.tm-del-btn` 去掉 3px / 4px 底边；进度条去掉渐变和流光；头像去渐变；章节小结按钮、流式光标改灰。
- `LogoMark.tsx` 用 `--rf-brand`；`CefrBadge.tsx` 的词汇档用灰阶；`ProfileMenu.tsx` / `AuthForm.tsx` 去掉内联的 4px 底边；`page.tsx` 去掉 XP / 🔥 和不再用的统计查询。
- 状态里的 ✓（对话里的「已在墨墨」、完成通知的图标）改用 `--rf-success-*`，绿色只用来表示状态。
- 文档：`docs/design-system.md` 的「颜色语义」重写。

- `check-tokens` 通过；单测 650 项通过；`e2e-chat-panel` 50、`e2e-word-library` 25、`e2e-pending-ui` 10、`e2e-card-toast` 15、`e2e-ask-thread` 15、`e2e-inline-gloss` 10 全过。

## 4. 纠正（2026-11-20，用户反馈）
第一阶段把「整个页面」都做成了灰色（难度标签、统计页的日历和柱状图、已导出标签等），统计页变得很沉闷。用户澄清：**中性（黑白灰）的是按钮等控件，不是整个页面。** 改为「颜色分三类」（详见 `docs/design-system.md` §1.0）：
- **控件**：黑白灰（主按钮近黑、进度条、导航、开关、头像不变）；
- **标签**：可以有颜色（难度 A 绿 / B 蓝 / C 琥珀，文章分类绿，已读完 / 已导出 / 卡片题型绿，来源 / 已读百分比灰）；
- **数据图表**：有颜色（学习日历、柱状图、难度明细条形恢复绿 / 蓝 / 琥珀；新增 `--rf-data`）。
不用紫色的决定不变。首页文本行、词库行的小标签恢复为标签（来源、分类、难度、已读状态；已导出「墨墨 ✓」绿色小标签）。
