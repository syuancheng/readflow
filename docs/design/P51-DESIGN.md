## 1. 设计简报（按 PR-01 顺序）

### 1.1 中心点（C-02 / TIP-03）
- 单词列表：每行的**词本身**（18px / 700），其次是释义（14px / 400 主文字色），再次是原句（14px / 次要灰）。
- 待推送：每张卡的**题面**（16px 正文）；标签、操作都是附属。
- 整页唯一的实心按钮：待推送页的「推送全部」。

### 1.2 分组 · 亲密性（P-01 ~ P-11）
- 信息组：筛选栏（状态 / 类型 / 文章）；工具条（选择 · 数量 · 排序）；一个词（词头行 + 原句 + 展开区）；一张卡（标签与操作 / 题面 / 翻面按钮）。
- 组内：词与喇叭、释义 8px；词头行与原句 4px；卡内标签→题面 12px，题面→翻面按钮 12px。
- 组间：词与词之间一条 1px 线 + 上下 12px 内边距；文章分组之间 24px；卡与卡之间一条 1px 线 + 16px。
- 取消「面板套框」：只有一层容器；展开区用左侧一条 2px 竖线表达从属，不再套框（P-10）。
- 视线路径：筛选 → 搜索 → 词（焦点）→ 释义 → 原句 → 展开后的完整释义 / 来源。

### 1.3 对齐（A-01 ~ A-11）
- 主对齐线：主区内容的左边缘。词、原句、分组标题、卡标签、题面、按钮全部落在这条线上；文字一律左对齐，无居中、无两端对齐。
- 星标和卡片的「修改 · 换一道 · 删除」靠右，落在主区右边缘（同一条右对齐线），是操作列，不是文字对齐。
- 复选框只在「选择」模式出现，出现时占据行首一列，词整体右移 32px，其余行同样处理，保持同一对齐线。

### 1.4 重复（R-01 ~ R-09）
- 圆角：容器 `--rf-radius-md`，小控件 `--rf-radius-sm`；1px 线贯穿（`--rf-border-width`）。
- 所有「次要操作」统一一种形态：无边框文字按钮 `.rf-btn-text`（28px 高、次要灰、hover 浅灰底；破坏性的 hover 变红）。需要强调的次要操作用 `.rf-btn-quiet`（1px 描边，P44 已有）。
- 新增重复元素：仅 `.rf-btn-text` 一种；删除的重复元素：4 种徽章颜色、📖 图标、3D 底边按钮。

### 1.5 对比（C-01 ~ C-09 / TX-01 ~ TX-11）
- 词（18px / 700 / 主文字色）对释义（14px / 400 / 主文字色）对原句（14px / 400 / 次要灰）：大小 + 粗细 + 颜色。
- 展开区：竖线 + 缩进 + 次要灰，与行本身区分。
- 状态：选中 / 展开的行用 `--rf-bg-hover` 整行底色；勾选用 `--rf-bg-selected`。

### 1.6 配色（COL-01 ~ COL-13）
- 沿用项目：中性灰为主；绿色只用于「推送全部」和选中项的对勾；红色只用于删除 hover；紫色（AI）不再用于卡片标签。**不新增色值。**

### 1.7 字体（TC / TF / TX / T）
- 沿用项目字体，字重只用 400 与 700。数字 `tabular-nums`。文字不用下划线强调（链接靠颜色 + 箭头 + hover）。

### 1.8 媒介与状态
- 状态：默认 / hover / `:focus-visible` / `:active` / disabled / 选中 / 展开 / 空 / 加载 / 失败。
- 窄屏（≤ 860px）：筛选栏收到顶部，词行保持两行结构；不做手机专用设计之外的新增。
- 打印：不处理。

## 5. 与方案的偏离
| # | 方案写的 | 实际 | 原因 |
|---|---|---|---|
| 1 | 页面顶部那行说明小字（「阅读时点过的词……」）孤立 | 保留 | 首页等页面都有同样的一行引导（重复原则），统一比去掉更一致 |
| 2 | 待推送页的复选框也平时隐藏 | 保持常显 | 在待推送页勾选是「推送选中的词」的核心操作，每次都要用；只有单词列表页的批量操作改成了「选择」模式 |
| 3 | 卡片头部「托福 · 口语」并进同一徽章 | 作为同一行里的次要灰字，不再有底色 | 题型标签保留中性底，风格标签降为文字，权重分明 |
