## 1. 设计简报（按 PR-01 顺序，写的是实际取值）

### 1.1 中心点（C-02 / TIP-03）
- 对话区的中心点是**最新一条 AI 回答的正文**（14px、主文字色 `--rf-text-primary`）。用户气泡、状态块、建议行、反馈行都是附属，权重低于正文。
- 初始状态（还没有回答时）的中心点是词本身（20px / 800 字重，沿用）。输入区用中性色，不用绿色或紫色实体按钮，不抢焦点。

### 1.2 分组 · 亲密性（P-01 ~ P-11）
- 信息组：① 词头与词典区（词头、释义、英文释义、上下文锚点）；② 一轮对话（用户气泡 + AI 回答 + 建议行 + 反馈）；③ 做卡状态块；④ 输入区。
- 组内间距：气泡 → 回答 12px（`--rf-space-3`）；回答 → 建议行 12px；回答 → 反馈行 8px；快捷问题之间 8px。
- 组间间距：一轮与下一轮 24px（`--rf-space-6`）；词典区与对话 24px；输入区与对话之间一条 1px 线 + 12px 内边距。
- 视线路径：词（起点）→ 释义 → 英文释义 → 对话回答 → 输入区（终点）。DOM 顺序与视觉顺序一致（没有用 `order` 或绝对定位重排）。

### 1.3 对齐（A-01 ~ A-11）
- 主对齐线：对话区的左边缘。词头、释义、英文释义、锚点、AI 回答、状态块、建议行、反馈行、输入框全部落在这条线上，文字一律左对齐。
- 唯一的破格：**用户气泡整体靠右**（例外 E-44-01）。气泡内文字仍左对齐；气泡右边缘落在对话区右内边线上（实测相距 4px，即对话区自身的内边距）。
- 不使用居中和两端对齐。

### 1.4 重复（R-01 ~ R-09）
- 沿用（加强已有重复）：圆角 `--rf-radius-md`（气泡、建议行、状态块）和 `--rf-radius-sm`（快捷项）；1px 边线（`--rf-border-width`）；12 / 14 两档字号；AI 紫（`--rf-ai-text` / `--rf-ai-soft`）只做点缀；快捷项形态和原「问 AI」菜单里的标签完全一致；进度环沿用 P33 的 `.rf-progress-ring`。
- 新增重复元素：无新增颜色、无新增字号、无新增圆角。只新增一种布局约定「用户靠右、AI 靠左」，在整个对话里重复。

### 1.5 对比（C-01 ~ C-09 / TX-01 ~ TX-11）
- 回答正文 14px / 常规字重 / 主文字色，对状态与反馈 12px / 次要灰：字号 + 颜色两个维度。
- 用户气泡 vs AI 回答：浅灰底 + 靠右 vs 无底色 + 满宽：底色 + 位置两个维度。
- 状态块：1px 边框 + 进度图形，区别于正文；失败时文字改用 `--rf-danger-text`。
- 「建议做成卡片」几字与按钮用 AI 紫 + 700 字重，对建议理由的 400 字重次要灰：颜色 + 字重。

### 1.6 配色（COL-01 ~ COL-13）
- 沿用项目现有关系：中性灰为主；绿色只用于「生成中」文字、完成对勾、反馈选中；紫色（AI）只做点缀（发送图标、快捷项 hover、建议行浅底）；红色只用于失败。**不新增色值。**
- 冷暖面积：整个右栏几乎是中性灰，彩色面积 < 10%。
- 对比度：正文 `--rf-gray-800` / 白 > 12:1；次要灰 `--rf-gray-600` / 白 ≈ 7:1；`--rf-ai-text`（紫 700）/ `--rf-ai-soft` 浅紫底 ≈ 6.5:1；`--rf-danger-text` / 白 > 7:1。

### 1.7 字体（TC / TF / TX / T）
- 沿用项目字体，不新增字族。字重只用 400 和 700。数字（百分比、秒数）加 `font-variant-numeric: tabular-nums`。
- 中文标点用全角，「做成卡片」等引号用「」；不用下划线强调；没有全大写。

### 1.8 媒介与状态
- 页面类型：详情页里的对话面板（`page-playbooks.md` 的「详情页 / 分页」+「通知卡只讲一件事」）。
- 状态：默认 / hover / `:focus-visible`（焦点环）/ `:active` / `disabled` / loading（`aria-busy` + 进度环）/ error（`role="alert"`）/ 空（没有对话时只有词典区）。
- 窄屏：**不在本期范围**（决策 D1）。≤ 1023px 时右栏堆到文章下面，取消固定高度；只验证没有横向溢出（768px 实测通过）。
- 深色模式：产品没有深色模式（媒介映射，见例外 E-44-05）。
- 打印：`@media print` 隐藏输入区。
- 言之有理：没有头像、没有入场动画、没有气泡尖角、没有装饰性图标；每个元素都有功能。
