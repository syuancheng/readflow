# P59 听力练习 · 设计简报

> 载体：阅读页正文下方的听力练习区（`/texts/[id]`）。本文件按《写给大家看的设计书》141 条规则集的 PR-01 固定顺序书写，顺序不可颠倒。
> 状态：设计阶段（原型 + PRD），未进入实现。配套：`docs/prd/P59-listening.md`、`docs/design/P59-listening.html`。

## 1. 中心点（C-02 / TIP-03 / PR-01）

整页第一焦点仍是**正文**（阅读页原有契约不变）。听力练习区作为正文下方的新区块，其唯一内部焦点是**当前播放句**——它靠浅灰底 + 左侧主色竖条 + 主色句首序号，与其余普通句形成全区块最强对比。一屏内只有一个「正在播放」句，不出现第二个同级焦点。

## 2. 分组（P-01 ~ P-09）

听力区自成一个视觉单元，与上方正文之间用区块间距 `space-6` 分开（组间），区内按三组组织（组内 `space-2`，组间 `space-4`）：

1. **材料组**：文档名 + 音频名 + 「更换材料」按钮，紧贴区块标题下方；
2. **播放控制组**：`整篇播放 / 按句播放` 分段控件、`重复 N 次` 步进器、进度文本，三者同一行容器；
3. **句子组**：句子列表（序号 + 文本 + 单句播放），当前句与练习输入区紧贴。

视线路径：材料组（这是什么材料）→ 播放控制组（怎么播）→ 当前句（正在听哪句）→ 练习输入（我要做什么）。DOM 顺序与视线顺序一致，不用 `order` 重排。

## 3. 对齐线（A-01 ~ A-09）

唯一主对齐线 = **正文卡片内容左边界**。区块标题、材料行、控制条、每一句、输入框左边界全部落在这条线上。唯一文本对齐方式 = **左对齐**，无居中、无两端对齐。SVG 图标居中属于图标内部对齐，不算文本对齐。

## 4. 重复元素（R-01 ~ R-07）

- **加强已有重复**：`.duo-card` 卡片（2px 边框 / 16px 圆角）、分段控件形态、`.duo-badge` 标签、主操作墨绿实心按钮、次操作描边按钮、令牌间距节奏——全部沿用阅读页现有组件，不新造视觉语言。
- **新增重复**：`序号 → 文本 → 播放按钮` 三栏句行结构在列表中逐行重复；当前句序号统一用主色。新增重复有明确用途（让每句可扫读、可单独点播）。

## 5. 强对比（C-01 ~ C-07 / TX-01 ~ TX-07）

至少两个维度叠加：

- 当前句 vs 普通句：结构上加左侧 4px 主色竖条 + 浅灰底（`--rf-bg-selected`），颜色上序号变主色、文字变主色，两个维度叠加；
- 主操作 vs 次操作：「播放」墨绿实心（`--rf-accent` 白字，对比 9.7:1）vs「显示答案」描边文字按钮；
- 层级字号：`--rf-text-2xl` 24px 区块标题 → `--rf-text-md` 16px 正文 → `--rf-text-xs` 12px 元信息，相邻比值 ≥ 1.5，无 14/16 假对比。

## 6. 配色关系（COL-01 ~ COL-13）

沿用本站已确立的**中性为主 + 单一强调**：界面主体是中性绿灰阶（`--rf-gray-*`），品牌绿只保留在内容层高亮（当前句竖条、序号、查词高亮）——延续用户 2026-11-20 确认的「绿只在内容层」裁决。主操作用墨绿 `--rf-accent`，不用亮绿。暖色面积为零。色板集中在 `tokens.css`，原型不临时挑色。

## 7. 字体（TC / TF / TX）

单一字族 DM Sans（无衬线类，含 400/600/700/800 极细到极粗成员），与阅读页正文一致——TF-01 协调方案，不引入第二字族（无「相似但不同」冲突）。字重覆盖 400/600/700/800；标题 24px/800 对正文 16px/400，跨 2 档以上。标点用弯引号（`&ldquo;` / `&rdquo;`），无全大写、无装饰下划线。

## 8. 媒介（COL-11 / TIP-05 / TIP-09）

- 宽屏：听力区随正文卡片同宽，沿用 61.8% 正文栏；
- 窄屏（≤720px）：双栏堆叠，句行三栏压缩为两行（序号与按钮同行、文本换行），步进器不溢出；
- 深色模式：全部取值走令牌，随系统/站点主题切换；
- 打印：`@media print` 隐藏播放控制条与输入区，句子文本保留（媒介映射，沿用既有 E-01）。
