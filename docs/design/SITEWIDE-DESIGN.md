## 1. 设计简报（按 PR-01 顺序）

### 1.1 中心点（C-02 / TIP-03）
- 阅读页：**文章正文**。文章内一级标题（h2）是正文区唯一放大的元素。
- 列表页（首页、词库）：**内容列表本身**。列表为空时，空状态的标题是焦点。
- 本次不新增元素，只把已有的「假对比」和「对齐分叉」收拢。

### 1.2 分组 · 亲密性（P-01 ~ P-11）

| 组 | 组内间距 | 组间间距 | 说明 |
|---|---|---|---|
| 文章标题 + 它领起的段落 | 0.6em（标题下） | 1.6em（标题上） | 沿用 `.rf-h`，上大下小，标题贴着自己的内容（P-04） |
| 图片 + 图注 | 0.45em | 1.35em | 沿用 |
| 空状态：图标 / 标题 / 说明 / 按钮 | 12 / 8 / 20px | 卡片内边距 48px | 沿用 |

视线路径：顶栏标题 → 文章 h2 → 正文 → 小节标题（h3–h6）→ 正文。DOM 顺序与视觉顺序一致。

### 1.3 对齐（A-01 ~ A-11）
- **唯一的文本对齐方式：左对齐**。整改后 `globals.css` 里只剩 `text-align: left`。
- 阅读页主对齐线是正文栏左边缘（1440 下 x = 65px，390 下 x = 65px）。文章标题、正文、图片、图注、块级公式、代码块都落在这条线上（见 `after/reader-body-1440.png`）。

| 位置 | 改前 | 改后 | 规则 |
|---|---|---|---|
| `.rf-figure figcaption` 与 `.rf-figure img` | 居中，图片 `margin: 0 auto` | 左对齐，图片左缘落在正文线上 | A-03 / A-05 |
| `.rf-math` 及 KaTeX 的 `.katex-display` | 居中 | 靠左，同 LaTeX `fleqn` | A-04 |
| `.duo-empty`（首页、词库、待推送） | 居中 | 左对齐。词库里与工具栏共用 16px 左缘，原先差 8px，改后 x = 405 | A-03 / A-05 / J4 |
| `.cefr-band-num` | 右对齐 | 左对齐，接在进度条终点之后，`tabular-nums` 保证上下对齐 | A-04 |
| `.tm-filter-label` | 右对齐 | 左对齐（「分类」「难度」等宽，视觉不变） | A-04 |

### 1.4 重复（R-01 ~ R-09）
- 加强已有重复：
  - 全部字族改为直接引用令牌 `--rf-font-sans` / `--rf-font-mono`。原来有 3 种写法：`var(--font-sans, …)`、手写 `ui-monospace, SFMono-Regular…`、`var(--font-sans), "PingFang SC"…`。其中 `.rf-md-code` 因此从系统等宽字体改为规范指定的 Geist Mono，与正文代码块 `.rf-pre` 和行内代码 `.rf-i-code` 一致。
  - 阅读页小节标题（h3–h6）统一为一种样式。
- 新增重复元素：无。

### 1.5 对比（C-01 ~ C-09 / TX-01 ~ TX-11）

阅读页标题实际字号（正文 `--rf-text-reading` = 19px，标题用 em）：

| 层级 | 改前 | 改后 | 与下一级的对比 |
|---|---|---|---|
| h2（markdown `#`） | 1.42em ≈ 27px / 800 / 底线 | **1.5em ≈ 28.5px** / 800 / 底线 | 与 h3 比，字号 1.5 倍，再加底线（结构） |
| h3（`##`） | 1.22em ≈ 23px / 800 | **1em = 19px** / 800 / 标题色 | 与正文同字号，靠粗细 800 对 400（跨 4 档）、标题色、上大下小的间距区分 |
| h4–h6（`###`+） | 1.06em ≈ 20px / 800 / 浅灰 | **与 h3 完全相同** | — |
| 正文 | 19px / 400 | 不变 | — |

改前 27 / 23 / 20 / 19px 是一串「相似但不同」：每级只差 1.15–1.2 倍，h4 还比正文只大 1px 并换成浅灰。这正是书中 12pt 对 14pt 的反例（C-03、TX-01）。改后只有两档，两档之间截然不同，同一档内完全相同（C-01）。

**取舍**：markdown 的 `##` 与 `###` 不再能从外观上区分。书中原则是「要么相同，要么截然不同」，而在 12–32px 的字号阶梯和 19px 正文之下，挤不出第三个相差 1.5 倍的档位。正文里的小节标题本来就是靠位置和粗细起作用的。请在截图上确认是否接受（`before/reader-body-1440.png` 对 `after/reader-body-1440.png`）。

字距：`.rf-h`、`.rf-home-hero`、页面标题 `main h1` 原有的 `letter-spacing: -0.01em` 删除（T-07）。在 24–32px 下这只相当于 0.24–0.32px，删除后肉眼看不出差别。

### 1.6 配色（COL-01 ~ COL-13）
- 本次不改任何颜色。互补关系沿用：黄绿（品牌 / 成功）对紫（AI），大面积中性灰白。
- 用真实令牌跑检查，会暴露 5 处既有的文字 / 背景对比不足（COL-08）。它们不在 P34 记下的 13 项里，登记为 E-08，另开任务处理（见 §4）。

### 1.7 字体（TC / TF / TX / T）
- 正文与界面：`--rf-font-sans`（DM Sans + 苹方，无衬线体），单一字族，采用协调方案（TF-01）。
- 代码：`--rf-font-mono`（Geist Mono），按 TC-02，等宽代码字体不算正文搭配。
- 音标：`--rf-font-ipa`，系统字体，只用于 IPA 字形。
- 字重只用 400 / 600 / 700 / 800（E-01），字号走 12–32 阶梯，阅读器内可用 em（E-02）。

### 1.8 媒介与状态
- 390px：阅读页、首页、词库的截图都没有横向溢出（脚本断言 `scrollWidth <= clientWidth`）。块级公式和代码块各自横向滚动（沿用）。
- 深色模式、打印：产品没有（E-05）。
