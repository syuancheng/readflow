## 1. 设计简报
### 1.1 中心点
- 推送完成：页面的中心点变成**结果**——一行「已推送 N 张卡到墨墨」，推送面板和进度条退场。
- 首页文本行：**标题**。
- 问卷：问题本身。

### 1.2 分组 / 1.3 对齐
- 推送完成后：离开「待推送」，切到「已导出」，词列表就在眼前（用户可以看到刚推的词带了「墨墨 ✓」）。结果提示在列表上方，12px 间距，与列表是两组。
- 首页行：标题与词数同一行（上），元信息一行纯文字（下），「开始阅读 →」靠右；元信息项之间只用 12px 间距分开，不套徽章。
- 问卷：一个 600px 的居中栏（标题、说明、卡片同一左边线）。

### 1.4 重复 / 1.5 对比 / 1.6 配色
- 元信息统一 12px 次要灰；唯一保留的小标签是难度（有悬停说明，是信息）。「✓ 已读完」用成功绿（状态）；结果提示里的 ✓ 也是成功绿（状态）。进度条只在推送进行时出现（近黑，P52）。
- 不新增色值。

## 2. 实现
- `PendingCards.tsx`：进度条只在 `running` 时渲染；结束后若有失败 / 错误，显示一段文字 + 失败列表 + 「重试失败的 N 张」（不画条）；全部成功（`failed === 0`）时 `load()` 之后通知上层 `onPushed({ done, audioMissing, remaining })`。
- `WordList.tsx`：收到 `onPushed`：`remaining === 0` → `router.replace('/words?status=done&pushed=N&missing=M')`（退出待推送）；还有没推的词 → 留在原地，只显示结果提示。新增 `pushedNotice` 属性和 `.rf-result` 提示行（✓ + 文字 + 「知道了」）；`initialStatus` 支持 `done`。
- `words/page.tsx`：读取 `pushed` / `missing`；`WordList` 带 `key`，参数变化时重新挂载，词的导出状态是最新的。
- `TextList.tsx`：去掉序号方块；元信息改成 `.tl-meta` 一行纯文字；已读百分比 / 已读完不再是徽章。
- `welcome/page.tsx`：内容放进 600px 居中栏；`.rf-survey-select` 去掉 400px 上限，随栏宽。
- 新：`src/styles/p54-pages.css`（`.rf-result`、`.tl-meta`、`.tl-done`、`.tl-go`）。
